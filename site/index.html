ModAnzer

Minecraft mod analyzer and injection checker for screenshares.

Not a hacking or malware tool. It only reads, and it's open source. It checks mods, the running game and Windows' records, then shows the results on screen. At the end it asks for your Discord ID, and only if you press Enter is a summary of the results sent to PrimeTiers staff.

Windows

Mod Analyzer, Injection Checker, System Check

Paste into PowerShell
powershell -ExecutionPolicy Bypass -NoProfile -Command "irm https://modanzer.onrender.com/ModAnzer.txt | iex"
Or download and run the file
Download ModAnzer.ps1
  1. Right-click the file → Properties → tick Unblock → OK
  2. Right-click it → Run with PowerShell

Android

Mod Analyzer for PojavLauncher and similar launchers

Download ModAnzer.apk
  1. Open the downloaded file to install it
  2. Allow installs from your browser if Android asks
  3. Tap Pick folder and choose your mods or launcher folder

What it checks

1. Mod Analyzer finds every mods folder (vanilla, CurseForge, Modrinth, Prism, Lunar, Dawn, Fast Client and more), checks each mod against Modrinth, Megabase and CurseForge, and searches unknown mods for cheat module names. It ends with a list of every cheat and which instance it was in.

2. Injection Checker runs while the game is open. It checks the launch options and loaded DLLs, reads Minecraft's memory (read-only) for cheat names and hidden manual-mapped programs, then watches live for injected DLLs, swapped mods and programs started from Downloads, Desktop or Temp.

3. System Check looks for traces: programs that ran and were deleted (BAM, Prefetch), cheat tools, cleared event logs and PowerShell history, logging services turned off, USB drives, the Recycle Bin, recent downloads, virtual machines and alt account names.

4. Full Screenshare runs all three in a row. For options 2–4 it asks for administrator rights so it can read Windows' records; the player can say no.

It does

  • Read your mods folders and fingerprint the .jar files
  • Look fingerprints up on Modrinth, Megabase and CurseForge
  • Read Minecraft's loaded DLLs and memory, without changing anything
  • Read Windows' records of programs that ran, logs and USB drives
  • List Minecraft account names (never tokens or emails)
  • Show everything on screen

It doesn't

  • Upload your files. Only mod fingerprints, plus a results summary if you press Enter to send it
  • Read passwords, tokens, emails, Discord or browser data
  • Change game memory or inject into any program
  • Change, move or delete files, or install anything
